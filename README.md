# Computer Graphics Labs

Labs 1-5 using Three.js. Each folder contains `index.html` and `main.js`.

Run `npx --yes http-server . -p 8080`, then open `http://localhost:8080/lab1/` (or lab2-lab5). Internet is required to load Three.js.

AI was used to generate and revise the code. Automated browser tests checked rendering, vector calculations, scene hierarchy, and keyboard controls.
